# 🛰️ OrbitWatch — мониторинг космических объектов в реальном времени

Система отслеживания текущего состояния космических объектов вокруг Земли
и в галактике: спутниковые группировки с отображением орбит, а также каталог
звёзд, планет и других объектов, чьи данные доступны из открытых источников.
Визуализация — ретрофутуризм в стиле терминалов старой космической фантастики.

## 1. Назначение системы

* **Для гостя:** просмотр каталога и звёздной карты без регистрации.
* **Для зарегистрированного пользователя:** персональные подборки объектов,
  уведомления о прохождении спутника, кастомизация визуализации.
* **Для администратора:** управление источниками данных, категоризацией
  объектов и контроль актуальности орбитальных параметров.

## 2. Бизнес-логика

### Клиент гостя (неавторизованный доступ)

* **Каталог объектов** — звёзды, планеты, туманности, галактики, спутники,
  фильтрация по категориям.
* **Орбитальная визуализация** — текущее положение спутниковых группировок
  и траектория их орбит на "радаре" в терминальном стиле.
* **Поиск** — по названию, типу объекта, категории спутниковой группировки.

### Кабинет зарегистрированного пользователя

* **Избранное / коллекции** — сохранение объектов и группировок в подборки.
* **Уведомления** — оповещение об изменении статуса объекта (например,
  спутник сошёл с орбиты, появились новые данные наблюдения).
* **Пресеты визуализации** — сохранение цветовой схемы терминала,
  масштаба орбитальной карты.
* **Таймлайн объекта** — история изменения параметров орбиты/положения.

### Модуль администратора (аналог оператора ОПС)

* **Управление источниками данных** — подключение/отключение внешних API
  (CelesTrak, SIMBAD, NASA Horizons), контроль лимитов запросов.
* **Категоризация объектов** — привязка объекта к категории
  (`SATELLITE`, `STAR`, `PLANET`, `NEBULA`, `GALAXY`) и подкатегории
  (для спутников — `NAVIGATION`, `COMMUNICATION`, `SCIENTIFIC`, `MILITARY` и т.д.).
* **Модерация** — проверка корректности синхронизированных данных,
  ручная коррекция при расхождениях.

### Сервис синхронизации данных (фоновый, аналог "службы доставки")

* **Обновление орбитальных параметров** — периодический пересчёт положения
  спутников по TLE-данным (алгоритм SGP4).
* **Изменение статуса объекта** — перевод объекта в `ACTIVE`, `INACTIVE`,
  `DECAYED` (сошёл с орбиты) на основе свежих данных источника.
* **Обработка задержек данных** — если источник не отвечает, объект
  помечается как `STALE` (данные устарели), пользователь видит это в UI.
